# Proyek 77: Tip & Bill Splitter (Kalkulator Tip & Bagi Tagihan)

Proyek ini adalah aplikasi web interaktif sederhana untuk menghitung persentase tip dan membagi tagihan pembayaran secara merata ke sejumlah orang. Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript**, cocok sebagai materi latihan manipulasi DOM dan logika aritmetika dasar untuk siswa pemula/SMK.
